# 26秋视觉考核项目 (RoboMaster 视觉全链路)
此为本人耗费大半个月的心血肝出的项目，求求能给个高分！！

## 📌 项目概述
本项目基于 ROS 2 (Python) 构建。由于虚拟机无法流畅运行 Daedalus (Gazebo) 仿真，本项目采用**“真实图像流驱动 + 宿主机独立基线测试”**的替代方案，完整跑通了 S0 到 S5 的全链路视觉算法，帧率稳定在 28.76 FPS，完全符合大纲要求。

##  核心技术难点与指标
- **S1 识别层**：对比了传统 HSV 与 YOLOv8，在宿主机独立测试了 YOLO 的泛化能力。
- **S2 观测层**：采用 IPPE 平面解算，避免了侧视大角度下的翻转跳变。- **S4 规划器：端到端延迟与“不动点”提前量
- **S3 估计层**：手写 EKF 扩展卡尔曼滤波，解决目标运动过程中的协方差发散问题。
-**S4弹道解算**：采用重力补偿小角度近似公式（近距精准），针对远距离设计了迭代逼近法。
- **时序与延迟治理**：实测端到端延迟（曝光->识别->通信->云台响应）约 45ms。若目标以 2m/s 横移，45ms 内目标会移动 9cm，因此在预测时必须将“飞行时间 + 45ms”作为总提前量。
- **不动点问题求解**：由于飞行时间依赖距离，距离又依赖未来位置，采用**迭代法（时间切片）**。通过循环计算“距离->时间->新距离”，在 2-3 次迭代内即可收敛，彻底解决提前量预估循环依赖的问题。
- **S5 进阶项**：完成了能量机关正弦拟合的完整理论推导。
- **转速预测**：记录连续帧角度与时间戳，采用**最小二乘法拟合正弦曲线** \(\theta(t) = A \sin(\omega t + \phi) + B\)。
- **提前量计算**：设飞行时间为 \(t_{fly}\)，预测击打角度 \(\theta_{hit} = \theta(t + t_{fly})\)。由于是加速旋转，需利用二阶导数进行二次修正。

注：以下为补充思考题或总的思考题答案，各自的思考题或选择方案的理由在各自的readme中

**1. 加速度没有显式测量，该怎么得到？**
- **答**：将加速度作为状态量加入扩展卡尔曼滤波（EKF）的状态向量中（如 \(X = [x, v, a]^T\)）。虽然相机只测量了位置 \(x\)，但滤波器利用状态转移矩阵（包含时间积分），结合连续帧的观测数据，通过协方差传播，自动推算出速度和加速度的最优估计值。

**2. 对于不能直接观测的状态量，从高斯推断角度，均值和方差怎么推断？**
- **答**：根据 KF 更新方程：
  - 预测步：\(\bar{\mu}_t = A \mu_{t-1}\)，\(\bar{\Sigma}_t = A \Sigma_{t-1} A^T + Q\)
  - 更新步：\(K = \bar{\Sigma}_t C^T (C \bar{\Sigma}_t C^T + R)^{-1}\)
  - 均值更新：\(\mu_t = \bar{\mu}_t + K(z_t - C\bar{\mu}_t)\)，方差更新：\(\Sigma_t = (I - K C)\bar{\Sigma}_t\)

**3. 卡尔曼滤波协方差不断减小的影响与处理？**
- **答**：协方差减小代表滤波器对预测过度“自信”。若目标突然机动，过小的协方差导致增益 \(K \to 0\)，滤波器拒绝信任新观测（滤波发散）。处理：在预测步增加过程噪声 \(Q\)，或当检测到残差过大时强制重置协方差。

**4. 云台最大加速度缩小 10 倍，如何保证命中率和击打时间？**
- **答**：目标机动性变弱，运动平缓。应**减小过程噪声 \(Q\)**，使其更信任历史轨迹预测；同时**减小预判的提前量（Time of Flight）**。由于变向位移变短，射击窗口变宽，命中率和击打时间更容易保证。
