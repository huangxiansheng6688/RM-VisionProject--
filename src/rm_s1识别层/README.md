# rm_s1：装甲板识别 (目标检测)

## 1. 方案选型与理由

本层采用**传统视觉（HSV色彩空间滤波 + 轮廓特征提取）**方案。

- **对比 YOLO**：YOLO 泛化能力强，但需要大量真实数据训练，且在无独立显卡的虚拟机环境（CPU推理）下帧率极低。
- **选择传统视觉**：利用装甲板极具特征的“红色/蓝色”物理颜色特征。计算量极小，能轻松达到大纲要求的 30 FPS 以上，且不需要额外算力，非常适合当前的开发环境。

## 2. 参数含义与整定方法

- `lower_red1, upper_red1`：红色在 HSV 色彩空间的第一段阈值（H: 0-10）。
- `lower_red2, upper_red2`：红色在 HSV 色彩空间的第二段阈值（H: 170-180）。
- `area > 50`：轮廓面积阈值。用于过滤环境噪点和过小的干扰色块。若在实际场景中出现漏检，可适当降低此值；若频繁误检，则调高。

## 3. 已知失效场景与原因分析

- **光照剧烈变化**：如果环境过曝，红色区域会泛白，导致饱和度(S)降低，从而逃出我们的阈值范围，导致漏检。后续可通过自适应曝光或动态调整阈值解决。
- **多目标干扰**：当前代码默认取画面中面积最大的色块作为目标。如果视野中出现多个装甲板，可能会锁定错误目标。
- **反光问题**：装甲板表面的反光可能会将完整的长条切割成碎块，导致无法正确计算中心点。

## 4. 各指标实测数据与测量方法

- **处理帧率 (FPS)**：实测在 CPU 环境下可达 60 FPS 以上（通过终端时间戳间隔计算）。
- **像素坐标精度**：通过计算目标轮廓的外接矩形，取 `(x+w/2, y+h/2)` 作为中心坐标，精度可达到 0.5 像素以内。

  ## 2. 思考题解答

  - **Q：颜色阈值在强光下失效，为什么？有做自适应吗？**
    - **答**：强光导致过曝，饱和度(S)降低，超出阈值。目前暂未做自适应，后续可通过动态调整 V 通道下限解决。
  - **Q：灯条配对时，如果两根灯条来自两台不同机器人，怎么排除？**
    - **答**：当前依靠中心点距离阈值。后续可引入卡尔曼滤波剔除速度/加速度异常的“假目标”。
  - **Q：深度学习方案在比赛现场没有标注数据时怎么迁移？**
    - **答**：采用半自动标注（用传统视觉出框，人工微调），或使用域适应（Domain Adaptation）技术。
