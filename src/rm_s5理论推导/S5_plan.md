# S5 进阶项：能量机关（大符/小符）方案设计

> 说明：由于目前缺乏真实能量机关场地与视频数据，本部分提供完整的理论算法架构与数学推导方案。

## 1. 目标识别与状态判定

- 中心 R 标提取：利用 HSV 阈值提取中心区域，通过轮廓面积与圆度筛选出 R 标，计算其最小外接圆圆心作为能量机关旋转中心。
- 叶片识别：通过极坐标变换，提取外围 5 个装甲板的轮廓，计算它们相对中心 R 标的极坐标角度。
- 状态判定：计算相邻两帧叶片角度的差值。若差值约为 0，判定为“未激活”（待机状态）；若角度持续变化，判定为“已激活”（旋转状态）。

## 2. 转速与方向预测（核心难点）

能量机关在激活后呈现正弦规律加速旋转。本方案采用最小二乘法拟合正弦曲线进行预测：

- 角度模型：θ(t) = A * sin(ωt + φ) + B
- 参数拟合：记录连续 N 帧的目标角度和时间戳 (ti, θi)。利用最小二乘法求解上述非线性方程，得出振幅 A、角频率 ω 和初相 φ。
- 方向与加速度：对拟合公式求一阶导数可得当前角速度 ω(t)，求二阶导数可得角加速度 α(t)。

## 3. 提前量计算与击打决策

- 飞行时间：设目标距离为 d，子弹弹速为 v = 25m/s，则子弹飞行时间 t_fly = d / 25。
- 预测角度：根据拟合的 θ(t) 模型，预测子弹到达时的叶片角度：
  θ_hit = θ(t + t_fly) = A * sin(ω(t + t_fly) + φ) + B
- 开火判定：提取装甲板上的“流水灯”特征（亮度变化）。只有当处于高亮状态的叶片旋转到预测的 θ_hit 角度时，触发 is_fire 信号。

## 4. 方案选型与失效场景分析

- 为何不用深度学习：能量机关的 R 标和装甲板具有极强的几何特征（对称性、环形），传统视觉的拟合速度极快（<1ms），且对旋转角度的计算精度远高于目标检测框。
- 融合方案：采用“卡尔曼滤波（平滑位置）+ 正弦曲线拟合（预测速度/加速度）”的融合方案。
- 失效场景：若流水灯亮度过高导致过曝，或外围叶片被遮挡，会导致拟合失败。需加入丢帧预测机制，利用历史角速度进行短时间盲推。
