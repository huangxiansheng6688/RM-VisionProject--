# rm_s3：估计器 (卡尔曼滤波与状态预测)

## 1. 方案选型与理由

采用**一维卡尔曼滤波 (1D KF)** 对目标的 Z 轴深度进行平滑与预测。

- **理由**：在实际视觉识别中，由于像素抖动，S2 输出的 3D 坐标存在大量高斯噪声。卡尔曼滤波能够在包含噪声的测量数据中，通过状态空间模型（预测-更新循环），估计出目标的真实状态（位置和速度），并有效抑制观测噪声。
- **答辩说明**：当前代码为一维滤波（主要平滑距离 Z），后续可直接扩展为多维 EKF（包含 X, Y, Z 及其速度）。

## 2. 参数含义与整定方法

- `q` (过程噪声协方差)：表示系统模型的不确定性。如果认为目标运动轨迹极其平滑，可调小 `q`；如果目标剧烈变速，需调大 `q`。
- `r` (测量噪声协方差)：表示传感器测量值的噪声。如果识别出的坐标跳变非常厉害，应调大 `r`，让滤波器更相信预测值。

## 3. 大纲思考题解答（核心拿分点）

- **Q：加速度没有显式测量，该怎么得到？**
  - **A**：可以将加速度作为状态量加入扩展卡尔曼滤波（EKF）的状态向量中（如 \(X = [x, v, a]^T\)）。通过观测位置 \(x\) 的变化，滤波器内部利用协方差传播会自动推算出速度和加速度的最优估计，无需显式的加速度计测量。
- **Q：对于不能直接观测的状态量，从高斯推断角度，均值与方差怎么推？**
  - **A**：对于未观测状态（如速度），其均值通过状态转移矩阵 \(F\) 与上一时刻状态相乘得到预测；其方差（协方差）通过 \(P = FPF^T + Q\) 传播。在更新阶段，利用卡尔曼增益 \(K\) 结合观测残差，修正这些不可观测状态的均值和协方差。
- **Q：卡尔曼滤波只要一直有观测，协方差不断减小会带来什么影响？如何处理？**
  - **A**：协方差不断减小意味着滤波器对自身的预测越来越“自信”。如果系统发生突变或模型不匹配，过小的协方差会导致滤波器无法及时响应（增益 \(K\) 趋于 0，完全不信任新观测）。处理方法：在预测步中加入过程噪声 \(Q\)，或引入“遗忘因子”强制增大协方差，保持对环境的敏感性。

    ## 1. 方案选型

    采用**扩展卡尔曼滤波 (EKF)**。相比滑动平均，KF 不仅没有相位滞后，还能通过状态方程预测目标未来的位置和速度。

    ## 2. 思考题解答
    - **Q：为什么不用滑动平均？**
      - **答**：滑动平均需要积累历史数据，会导致严重的相位滞后，无法满足实时击打高速运动目标的需求。
    - **Q：装甲板切换时，滤波器会不会被“锁死”？**
      - **答**：会的。如果目标ID突变，旧协方差极小会导致新目标无法收敛。处理方法：检测到目标跳变时（残差超限），重置协方差矩阵。
    - **Q：过程噪声 \(Q\) 和观测噪声 \(R\) 怎么取？**
      - **答**：\(Q\) 反映模型不确定性（机动性），\(R\) 反映传感器噪声（识别抖动）。静止时 \(Q\) 取小，剧烈运动时 \(Q\) 取大。
