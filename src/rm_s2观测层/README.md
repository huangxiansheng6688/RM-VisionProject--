# rm_s2：观测器 (从像素到三维坐标)

## 1. 方案选型与理由

本层采用**相机针孔模型反投影 + 坐标系转换**。

- 输入 S1 识别出的目标中心像素坐标 `(u, v)`。
- 由于当前缺乏真实物理标定环境，算法假设目标深度 \(Z=2.0m\)。利用已知的相机内参矩阵（焦距 \(f_x, f_y\) 和光心 \(c_x, c_y\)），通过相似三角形原理反推目标在相机坐标系下的 \(X\) 和 \(Y\) 真实坐标：
  - \(X = (u - c_x) \times Z / f_x\)
  - \(Y = (v - c_y) \times Z / f_y\)

## 2. 参数含义与整定方法

- `cx, cy`：相机光心在图像坐标系下的坐标（通常为分辨率的一半）。
- `f`：相机的焦距（像素单位）。
- **整定方法**：在真实部署时，应使用 `cv2.calibrateCamera` 和棋盘格进行标定。如果发现解算出的 X 坐标偏左/偏右，微调 `cx` 值即可。

## 3. 已知失效场景与原因分析

- **深度 Z 固定导致误差**：当前固定 Z=2.0m，如果目标实际距离为 5m，解算出的 X、Y 会发生比例放大。真实场景必须利用 `cv2.solvePnP` 解算真实姿态。
- **相机畸变**：图像边缘存在桶形/枕形畸变，未进行去畸变处理会导致边缘区域解算误差急剧增大。

## 4. 大纲思考题解答

- **Q：为什么图像与 TF 时间戳不同步会导致运动目标误差？**
  - **A**：如果图像时间戳是 \(t_1\)，而云台 TF 时间戳是 \(t_2\)。在 \(\Delta t = t_2 - t_1\) 期间，如果目标在运动，我们使用旧图像（旧位置）配合新云台角度进行解算，就会产生一个位移偏差。速度越快，偏差越大。
- **Q：如果相机外参标定有 1° 偏差，对 8m 外的目标意味着什么？**
  - **A**：根据三角函数，距离 \(d=8m\) 时，横向误差约为 \(8 \times \tan(1^\circ) \approx 0.139m\)（即 13.9 厘米）。这意味着如果装甲板宽度只有 14cm，该误差将直接导致子弹脱靶。



# rm_s2：观测器

## 1. 方案选型

采用 `SOLVEPNP_IPPE_SQUARE`。由于装甲板是平面靶标，IPPE 算法相比迭代法，在大角度侧视（场景 E）时解算更稳定，不会出现翻转跳变。

## 2. 思考题解答

- **Q：单目 PnP 在什么条件下解算会跳变？**
  - **答**：当目标距离过远（像素过少导致角点提取不准），或观测角度极小（接近共线）时，位姿解算会出现二义性，导致翻转跳变。
- **Q：为什么图像与 TF 时间戳不同步会导致角度误差？**
  - **答**：如果图像是 \(t_1\)，TF 是 \(t_2\)，期间目标发生位移，用旧图像算出的坐标再去配新云台角度，就会产生系统性的角度偏差。
- **Q：相机外参标定有 1° 偏差，对 8m 外目标意味着什么？**
  - **答**：横向误差 = \(8m \times \tan(1°) \approx 0.139m\)（13.9 厘米），这直接超过了装甲板的一半宽度，会导致脱靶。
